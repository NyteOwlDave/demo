# Test John's Project

> ( `parseEval` )

```bash
swiftc -o pscript parseEval.swift
```

Builds a native binary that will run on `Linux`, `Windows`, and `ARM Microcontrollers`.

If you download the demos, run:

```bash
pscript
load Demos/hanoi.bos
run
```
