Lumina Gfx API Notes

( Web Demos )

Description

The Lumina Gfx API supports a wide array of Wb-based demos.

The Palette Analyzer was first. Though the concepts existed with Midge API and Madge Gfx App, the palette analyzer served as a sandbox for a fresh new implementation of the "Line Plotter" style Graphics Engine.

Eventually, the embedded code was extracted and given the name Lumina. Though it remains closely related to Midge.

After extraction, the Lissajous Demo imported the API and became another powerful example of the usefulness of this Graphics and Math module.
