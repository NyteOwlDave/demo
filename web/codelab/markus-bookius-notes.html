Origin

Markus began life as a Code Lab experiment. Checking out the IDE and learning its features and limitations.

After a little while, it grew into a simple Bookmark Database. It combines features from both Raindrop and my Store Key Notes Manager.

Like Raindrop, Sulu, or Dorothy, it manages collections of URL Addresses.

Like SKNM, Venus, or Slideshow, it offers the ability to navigate using "Media Control" arrows.
